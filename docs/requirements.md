# 要件定義メモ

## 機能一覧
1. 記事一覧・詳細表示（カード形式の一覧から詳細ページへ移動。本文はMarkdownで表示）
2. 記事作成（本文のリアルタイムプレビュー付き）
3. 記事編集（既存の内容を読み込み、更新できる）
4. 記事削除（確認ダイアログのあとに削除）
5. ログイン制御（ログイン中の投稿者本人だけ編集・削除ができる）
6. 記事検索（タイトル・本文が対象、大文字小文字を区別しない）

## データ項目
- id：記事の番号
- title：タイトル
- content：本文（Markdown）
- author：投稿者名
- createdAt：作成日

## APIエンドポイント
- GET /articles：記事一覧を取得
- GET /articles/:id：記事1件を取得
- POST /articles：記事を新規作成
- PATCH /articles/:id：記事を更新
- DELETE /articles/:id：記事を削除
